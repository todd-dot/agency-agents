## 2. Testing methodology (the repeatable rules)

| Element | TETRA (mature) | Snead (launch) | She's Birdie (scale) |
|---|---|---|---|
| Test budget | 10–15% of Meta spend | Shared budget, sized for ≥5 leads/message | Guardrailed by bid caps |
| Fair test | $1.5–2K per concept | 2–3 weeks per phase | 48-hr windows |
| Kill rule | ≤3x ROAS after fair test | Spend 2× goal, 0 leads → off | CPA > $75 for 48hrs → cut 50% |
| Scale rule | ≥7x ROAS | Lowest CPL (≥5 leads) → Test 2, then scale | CPA < $45 for 48hrs → +20% |
| Concentration cap | — | — | No creative >30% of purchases (SB121 at 54.6% flagged); AJF plan: no ad >20% of spend |
| Freeze | Oct Q4 gate: no new tests Nov/Dec | — | Max daily ramp 25%; budget floor $3.5K/ceiling $10K |

**Naming/structure conventions observed:** date-prefixed campaigns (`05-15-26_Broad-STO-CC_INC`, `08-13-26_configurator_HV`, `10-05-26_HV_oct-copy-bank`); ABO test tags (`1.16_BID-MULTIPLIER_ABO_SALES_US_1DC`); funnel tags (`Post14_TOF_F_Broad_Video`); STO = audience-segment campaigns for TETRA.

**What "fair test" means in practice:** enough spend for statistical signal ($1.5–2K/concept at TETRA scale; ≥5 leads at Snead scale; 48 hrs at Birdie scale) — scaled to account size, not fixed.

## 3. Creative workflow

**The Tether Messaging Engine** (used for Snead, BookNook, Metto — Todd's/T.S. Growth's proprietary method):
1. **Brand Brain / research** (Gemini deep research, reviews, voice-of-customer) → customer language
2. **Insight Map** — insights written in customer's voice, tagged: **Zone** (1 calm → 4 pain), **Self** (Actual/Ought/Ideal), **Motivator** (Empowerment, Competence, Security, Autonomy, Esteem, Belonging, Nurturance…), **TEEP** (Trigger/Explore/Evaluate/Purchase)
3. **Scoring** — ESS (emotional strength) + GAP (market whitespace) − Friction → **Response score**; rank insights
4. **Hooks + formats** per insight (5 hooks each; formats: Big Words, Customer Quote, Offer Box, Property Scene, UGC, reveal video, authority…)
5. **Client-facing test plan** (plain-language PDF) derived from the internal audit — client never sees Zone/Self/Motivator columns
6. **Ad copy sheet** — full primary text / headline / description / CTA per ad, with voice + compliance rules baked in
7. **Production** — designer builds; some ads made before client OK (Snead: 4 of 12 done pre-approval), asset gaps tracked per ad ("Needs permission", "Needs cab photo", "From your posts")

**Roles:** Todd = strategist (insight map, test design, copy); designer/producer builds (Josh for Metto; Caleb/Brennon supply UGC-style delivery content for Snead); client supplies proof assets (quotes with permission, photos, financing terms).

**Iteration loops:** TETRA = monthly one-pager verdicts + quarterly concept tests; Birdie = weekly creative review + monthly refresh (5–10 new ads) + quarterly new-concept test; Snead = phased 3-test sequence (message → design → first line).

## 5. Cross-client patterns — the Uptick paid-social OS

1. **Message-first testing.** Every account tests *messages* before *designs* (Snead 6×2; TETRA four message lanes; Birdie concept CPO ranking). One variable at a time.
2. **Tether insight framework as the angle factory.** Zone/Self/Motivator/TEEP + ESS/GAP/Friction scoring → ranked insights → hooks → test plan. Used identically across Snead, BookNook, Metto.
3. **Explicit kill/scale math, sized to account.** Same skeleton (fair-test spend → kill threshold → scale threshold), different numbers per account scale.
4. **Concentration risk is a tracked metric** (30% purchases / 20% spend benchmarks).
5. **Promo calendar drives the year** (Birdie: Valentine's/IWD/Mother's Day/BTS/BFCM; TETRA: Father's Day template, waterfowl season, Vets/BF Oct 1 live, Q4 freeze).
6. **Broad targeting + strong creative** over micro-targeting (Snead: broad 28+ in 75-mi radius; Birdie: broad prospecting campaign; bid caps do the work).
7. **Bid cap > tROAS** as default posture where tested (Birdie: 15% CPO edge).
8. **Client-facing vs internal split:** internal docs carry scoring/methodology; client sees plain-language plans and one-pagers.
9. **Proof assets are the bottleneck** — every plan has a "what we need from you" list (quotes with permission, photos, financing terms). The agent should track asset gaps per ad.
